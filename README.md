# Positions History by frankforges — releases

Release channel for the Positions History add-on for NinjaTrader 8.

- **Download:** see [Releases](../../releases). Import the zip in NinjaTrader:
  Control Center → Tools → Import → NinjaScript Add-On.
- **Activation:** the add-on works only on machines its author has activated. After installing,
  open Control Center → New → frankforges → Positions History, copy the Machine ID it shows, and
  send it to the author.
- `licenses.txt` / `licenses.sig` are the signed activation list the add-on reads. They're
  published automatically; don't edit them here.
